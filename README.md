# Galaxy ATM System

Плагин EuroScope для РЦ/ДПК Санкт-Петербург (ULLL). Свои метки (формуляры), символы трасс, панель управления, список РЦ, согласование со смежником, зоны и SIGMET, предупреждение о конфликтах (STCA) и пеленгатор (АРП).

Подробное руководство диспетчера — [GalaxyATMSystem_Manual.pdf](GalaxyATMSystem_Manual.pdf). Что менялось и что ещё не проверено — [CHANGELOG.md](CHANGELOG.md).

## Что умеет

- **Метки РЦ, ДПК и КДП.** Свой вид для каждой работы, выбирается по позиции или командой `.formular`. На развёрнутой метке РЦ — XFL/COPX, назначенные курс и скорость, тип и авиакомпания. Средняя кнопка открывает вкладку mode-s.
- **Окна назначений:** CFL/XFL, курс (в том числе перетаскиванием вектора с учётом радиуса разворота), скорость и Мах с модификатором, RVSM, передача, COPX, свободный текст.
- **Согласование со смежником.** Уровень и точка выхода/входа, окно Accept/Reject. RVSM, модификатор скорости и результат согласования передаются смежнику, у которого тоже стоит плагин.
- **Список РЦ** (`.rc`): на радаре или отдельным окном, с фильтрами и сортировкой.
- **Зоны** из `Zones.ULLL.json`. Активность берётся из AUP и NOTAM, предупреждение о приближении — APW. **SIGMET** рисуются по выбранным FIR.
- **STCA.** Потеря и прогноз потери разделения, минимумы по районам аэродромов. Прогноз на экран не рисуется, на метке и в списке он отмечается как SSA.
- **Пеленгатор (АРП).** Пеленг на того, кто передаёт, по данным TrackAudio/AFV.
- **Прочее:**
  - линейка;
  - зарисовки на карте (текст, линии, окружности);
  - маршруты;
  - векторы по времени, расстоянию и плану;
  - дуги спутного следа;
  - ATIS, QNH и эшелон перехода;
  - выдача кодов ответчика;
  - русский и английский интерфейс.
- **Вход.** Работает только после входа по CID и фамилии, когда VATSIM показывает позицию. В тренировочной сессии (sweatbox) вход не нужен.

## Установка

Установщик `GalaxyATMSystemSetup-<дата>.exe` ставит `GalaxyATMSystem.dll`, а также `GalaxyATMSystem.json` и `Zones.ULLL.json`, если их ещё нет; при обновлении конфиги не трогаются. Кроме того, ставится шрифт Inter. Плагин подключается в EuroScope: *Other Set → Plug-ins → Load*.

Настройки лежат в `GalaxyATMSystem.json` рядом с DLL: аэродром, QNH, позиции и их `Designation`, SIGMET, зоны и их цвета, APW, коды ответчика, STCA, пеленгатор, ATIS. После правки — команда `.reload`.

## Команды

| Команда | Что делает |
|---|---|
| `.ulll` | Показать или скрыть панель |
| `.formular` | Показать или скрыть метки |
| `.formular auto\|ctr\|app\|twr` | Вид меток: по позиции, РЦ, ДПК, КДП |
| `.rc`, `.rc <проценты>` | Список РЦ, масштаб списка |
| `.atis` | Окно буквы ATIS |
| `.sigmet` | SIGMET вкл/выкл |
| `.zones` | Зоны вкл/выкл, сколько активно |
| `.stca`, `.stcainfo` | STCA вкл/выкл, состояние |
| `.rdf` (`.arp`) | Пеленгатор вкл/выкл |
| `.ruler`, `.rulerclear`, `.rulerbtn 0\|1\|2` | Линейка: отмена, убрать все, боковая кнопка мыши |
| `.eng`, `.rus` | Язык интерфейса |
| `.reload` | Перечитать `GalaxyATMSystem.json` |
| `.logout` | Выйти |
| `.galaxyperf` | Замер быстродействия: раз в 10 с в лог пишется время кадра и каждой части |
| `.galaxydiag`, `.symbols` | Диагностика подключения и выбранного борта; символы трасс |

Лог — `GalaxyATMSystem.log` рядом с DLL.

## Сборка

Нужны Visual Studio или Build Tools с MSBuild (Win32, набор инструментов v145). Для установщика нужен Inno Setup 6.

```bat
installer\build.cmd
```

Скрипт собирает `Release\GalaxyATMSystem.dll` и установщик в `dist\`. Если `vswhere` не находит MSBuild (стоят только Build Tools), DLL собирается напрямую:

```bat
"C:\Program Files (x86)\Microsoft Visual Studio\18\BuildTools\MSBuild\Current\Bin\MSBuild.exe" GalaxyATMSystem.sln -p:Configuration=Release -p:Platform=Win32
```

## Устройство

- `GalaxyATMSystem/Core` — общие функции: геометрия, рисование, слежение за бортами.
- `GalaxyATMSystem/Plugin` — плагин EuroScope: события планов, теги, вход, загрузки (METAR, SIGMET, ATIS, AUP, NOTAM), коды ответчика, sweatbox, настройка пеленгатора.
- `GalaxyATMSystem/Screen` — радарный экран: метки, символы, векторы, окна, панель, список РЦ, зоны и SIGMET, STCA, пеленгатор.
- `GalaxyATMSystem/*.cpp` в корне — конфиг, зоны и APW, SIGMET, STCA, пеленгатор, ввод текста, журнал.
- `installer/` — Inno Setup и шрифты.
- `tools/afv-sim` — имитатор AFV для проверки пеленгатора без TrackAudio.
- `tools/sweatbox` — сценарий тренировки для проверки согласования.
