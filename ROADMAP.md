# Galaxy ATM System — Roadmap

Этот документ определяет порядок разработки Galaxy ATM System и является основным рабочим планом проекта.

Задачи добавляются и изменяются по мере развития проекта. Новую функциональность сначала фиксируем здесь, затем реализуем по порядку.

## Статусы

* `[ ]` — запланировано
* `[~]` — в работе
* `[?]` — тестирование
* `[x]` — выполнено
* `[-]` — отложено

Приоритеты:

* **P0** — необходимо для текущей версии
* **P1** — важно для следующего этапа
* **P2** — запланировано
* **P3** — в дальнейшей перспективе

## Правило работы с roadmap

Новая функция сначала добавляется в этот документ.

После начала разработки задача получает статус `[~]`.

Перед завершением она проходит проверку на сервере и, при необходимости, на плагине.

Только после успешного тестирования задача переводится в `[x]`.

Крупные изменения, затрагивающие БД или архитектуру, должны сначала иметь отдельную задачу в roadmap.
